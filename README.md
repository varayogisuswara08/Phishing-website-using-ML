# 🛡️Phishing detection website using SVM and Light GBM models
This project detects whether the website is legitimate or phishing website using SVM and Light GBM model.
These 2 models are trained independently and then combines via sstacking and are improved with more predicitions<br>
The system also provides an important predictions that influnced an intercative web dashboard.
##
# 📌 Project overview 
Phishing attack are very common and very dangerous cyberthreat in today's world.Attackers are creating an fake websites and links for the people and take all the nessary information and finacial information without their authority.<br>
__Taking passwords__ <br>
__Fake emails__ <br>
This project uses machine learning and Explainable AI to detcet suspicious URLs and provide and understanble explaination of prediction.
The main idea of this project is detecting the URL is phishing or legitimate and giving the user the correct URL and the length of the URL.
